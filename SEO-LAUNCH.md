## До реального SEO-продвижения обязательно
1. Утвердить текст услуг, реквизиты, гарантию и фактические характеристики работ с заказчиком.
2. Приобрести основной домен, развернуть рабочий HTTPS-хостинг и подключить протестированную форму MAX. Не включать её на GitHub Pages.
3. На **основном домене** снять `noindex,nofollow` с главной и страниц услуг, добавить абсолютные canonical, `robots.txt` и `sitemap.xml` с корректными адресами. На демонстрационном GitHub Pages запрет на индексацию остаётся.
4. Настроить Яндекс Вебмастер: подтверждение домена, загрузка sitemap, индексирование и фактический регион Нижний Новгород.
5. Добавить достоверные данные в Яндекс Бизнес. Не придумывать адрес офиса.
6. Подключить Яндекс Метрику, проверить цели отправки заявок/звонков, затем запускать Яндекс Директ.
7. Измерить скорость и Core Web Vitals с реального домена, проверить мобильные страницы и загрузку шрифтов.
8. Проверить политику и обработку персональных данных при переходе на PHP/MAX и внешние сервисы.
9. Дополнять кейсы уникальными техническими подробностями. Не создавать шаблонные страницы для каждого района без реальной пользы.

SEO не гарантирует фиксированных позиций. Сайт на GitHub Pages остаётся закрытым от поисковой индексации до полного запуска.
