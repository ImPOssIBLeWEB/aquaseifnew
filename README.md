# AquaSeif — демонстрационный сайт

Лёгкий адаптивный сайт: HTML + CSS + JavaScript. Без Node.js, базы данных и сборки.

## Запуск
Откройте `index.html` в браузере. Для локального HTTP-просмотра: `python -m http.server 8000`, затем http://localhost:8000.

## Содержимое
- `assets/images/` — 10 оптимизированных WebP-фотографий, предоставленных для проекта.
- `assets/video/ground-stabilization.mp4` — сжатое видео 27 секунд, воспроизводится по нажатию.
- `assets/styles.css`, `assets/script.js` — оформление, мобильное меню, галерея, анимации, UTM-поля.
- `privacy.html` — временная демонстрационная заглушка, не готовая юридическая политика.

## Важно перед публикацией
1. Форма **намеренно отключена** — серверная интеграция с MAX ещё не готова. Не включайте кнопку до успешных тестов доставки/ошибок, обработки персональных данных и согласия.
2. В `index.html` установлено `noindex,nofollow` для демонстрационного домена. Убрать только при реальном запуске с доменом, доступной политикой, настройкой Метрики и проверкой SEO.
3. Подтвердить с заказчиком, что фотографии и видео разрешено публиковать, особенно кадр с человеком.
4. Уточнить подписи работ, гарантийные условия, юридические данные владельца и применимые услуги.
5. Для MAX токен хранить исключительно на сервере (например, PHP-обработчик); нельзя прописывать его в HTML/JS.
6. Проверить Lighthouse, телефонную вёрстку и реальные формы на выбранном хостинге.

## AquaSeif: три фотообъекта и подтверждение квалификации

Для новых блоков используются 18 отдельных файлов WebP в `assets/images/`:

- `case-seams-01.webp` ... `case-seams-05.webp` — деформационные швы подземного перехода.
- `case-chamber-01.webp` ... `case-chamber-05.webp` — бетонно-монолитная барокамера.
- `case-injection-01.webp` ... `case-injection-05.webp` — инъектирование подземного пешеходного перехода.
- `alexey-kuznetsov.webp`, `alexey-qualification-certificate.webp`, `alexey-qualification-protocol.webp` — портрет и документы специалиста.

До фактической загрузки изображений соответствующие секции скрыты, чтобы не было битых картинок. После загрузки всех файлов соответствующей серии блок появится автоматически. Публикация документов и портрета требует разрешения специалиста.

## Редизайн и новые объекты (v3 Bright)

Внедрена новая цветовая тема: синий/бирюзовый, жёлтый для основных кнопок, светлые секции, более заметные карточки и контрастная мобильная панель. Проект остался HTML/CSS/JS без зависимостей. 

Ещё 15 фотографий необходимо загрузить в `assets/images/` (см. отдельный ZIP):
- `case-lower-seam-01.webp` … `case-lower-seam-05.webp` — инъектирование нижнего блочного шва.
- `case-cellar-kstovo-01.webp` … `case-cellar-kstovo-05.webp` — гидроизоляция погреба, Кстово.
- `case-basement-01.webp` … `case-basement-05.webp` — гидроизоляция подвального помещения жилого дома.

В JS уже настроена проверка готовности всех 5 файлов каждой серии: пока файлы не загружены, соответствующий кейс скрыт и остальные блоки работают. MAX-форма в GitHub Pages остаётся отключённой.
